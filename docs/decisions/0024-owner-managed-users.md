# 0024 — Owners create users; temporary passwords instead of invites and reset links

- Status: Accepted (supersedes 0023)
- Date: 2026-10-17

## Context
The owner wants simple authentication: no signup, no invites. v1 has no email delivery, so an
invite link has to be handed over manually anyway; creating the user directly is simpler and,
done right, just as safe. Spec addendum A9 records the decision.

## Decision
- **Create:** `POST /organizations/:id/users {email, role}` (`org:users`): owners any role,
  admins `member` only (re-checked under the org row lock). Platform admins:
  `POST /admin/organizations/:id/owners {email}`. First owner of the instance: `pnpm cli create-owner`.
- **Temporary password:** 4×5 characters from 54 unambiguous symbols (~115 bits), generated by
  the server with `crypto.randomInt`, returned once, stored only as Argon2id. The owner never
  chooses or learns the user's real password.
- **Forced change:** `users.must_change_password`. Such a session reaches only `GET /auth/me`,
  `POST /auth/logout[-all]` and `POST /auth/password` (decorator `@AllowedBeforePasswordChange`);
  everything else is `403 PASSWORD_CHANGE_REQUIRED`. The new password must differ and pass policy.
- **Reset:** `POST /organizations/:id/members/:userId/password-reset` (owners): new temporary
  password, all sessions revoked. Refused for the owner themself, platform admins and accounts
  that are members of other organizations (an owner must not take over access elsewhere);
  those go through `pnpm cli reset-password <email>` (operator, any account).
- **Existing emails:** creating a user with an email that already has an account is `409`.
  Adding an existing account to a second organization is not offered over HTTP in v1.
- Audit: `user.created`, `user.password_reset` (never the password).
- Invites are removed (migration 0007 drops the table; 0006 stays, migrations are forward-only).

## Consequences
Less code and no public token routes. The owner hands over a temporary password (like a reset
code); the forced change limits what a leaked one is worth. Multi-organization accounts need the
operator. Revisit with email delivery or SSO.
